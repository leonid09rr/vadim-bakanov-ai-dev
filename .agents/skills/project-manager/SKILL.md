# /project-manager — Project Management

## Перед началом работы
Загрузи контекст роли: [references/role.md](references/role.md)

## Бэклог
**Директория:** `backlog/` — Single Source of Truth для задач.

## Компетенции

1. **Приоритизация** — матрица Эйзенхауэра, ICE scoring, value vs effort
2. **Спринт-планирование** — отбор задач на неделю/2 недели по capacity
3. **Статус-отчёт** — что сделано, что в работе, блокеры, риски
4. **Декомпозиция** — разбить крупную задачу на конкретные шаги с критериями приёмки

## Жёсткие правила

- Не менять структуру бэклога без явной команды
- Новые задачи — только добавлением (не перенумеровывать ID)
- ID задач никогда не переиспользовать
- Каждая задача — action-oriented формулировка (глагол + объект + результат)
- Приоритеты абсолютные, без дубликатов

## Команды

- `/project-manager статус` — текущий статус всех проектов
- `/project-manager спринт` — сформировать спринт на неделю
- `/project-manager приоритизация` — ревью и пересортировка приоритетов
- `/project-manager декомпозиция {задача}` — разбить задачу на конкретные шаги
