# Auto-Backup

После завершения значимой работы — предложи пользователю сделать бэкап.

## Что считается значимой работой

Предлагай бэкап после:
1. **Завершение задачи** — создание/редактирование файлов
2. **Работа с данными** — обновление бэклога, отчётов
3. **Создание документации** — новые README, архитектурные документы
4. **Изменение конфигурации** — новые скиллы, правила, промпты
5. **Множественные изменения** — 3+ файлов за сессию

## Что НЕ является значимой работой

НЕ предлагай бэкап после:
- Только чтения и анализа (без изменений файлов)
- Ответов на вопросы без редактирования
- Незавершённой работы (пользователь явно продолжает)

## Формат предложения

После завершения значимой работы добавь в конец ответа:

```
---
Сделать бэкап в GitHub? Скажи "да" — закоммичу и запушу.
```

## Важно

- НЕ делай бэкап автоматически — только предлагай
- Пользователь сам решает, когда пушить
