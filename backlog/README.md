# Backlog

Single Source of Truth для задач проекта.

## Формат задач

| Поле | Описание |
|------|----------|
| ID | Уникальный номер (никогда не переиспользовать) |
| Название | Action-oriented заголовок (~80 символов) |
| Описание | Что сделать, критерии приёмки |
| Приоритет | 1-100 (1 = самый важный), абсолютный |
| Статус | `TO DO` / `WIP` / `DONE` / `ON HOLD` |
| Дедлайн | YYYY-MM-DD (если есть) |

## Правила

- Новые задачи — только добавлением строк (не перенумеровывать)
- Каждая задача — глагол + объект + результат
- Приоритеты абсолютные, без дубликатов
- Статус обновляется сразу при изменении

## Управление

Используй скилл `/project-manager` для:
- Формирования спринтов
- Приоритизации
- Декомпозиции задач
- Статус-отчётов
